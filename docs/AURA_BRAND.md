# AURA visual identity

Reference supplied by the repository owner: https://chatgpt.com/s/m_6ae10276a6388191bc4a4122700cc93c (AURA minimalist identity board).

The Android header and About page use a vector reconstruction of the overlapping cyan/blue/indigo wave and geometric wordmark. The launcher uses the wave on deep navy. These are scalable interpretations of the supplied raster reference, not an extracted original logo/font. Original vector master files would allow exact geometry matching. The board contains branding, not a navigation icon family; existing functional navigation icons remain.

Assets are bundled locally; there are no runtime image downloads, extra permissions or monitoring changes. Gradients use the reference palette (#3EE6E5, #598BFF, #6366F1, #8B5CF6, #081736). Existing accessible text and icon labels remain. Physical launcher appearance across OEM masks remains a device check.
